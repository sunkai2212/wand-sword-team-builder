# 阵容工具交互优化设计

## 目标

优化《杖剑传说·4v4阵容图》网页的主要使用体验：界面更像轻量游戏工具，角色可拖动换位，技能选择页直接展示当前职业在当前转数范围内可用的全部图标。

## 范围

- 前端美化：只调整现有页面、站位盘、角色编辑卡片、弹窗和按钮的视觉层级，不引入后台、不改变导出图片版式。
- 角色移动：在现有“点选角色再点空位移动”的基础上，增加拖拽到空位移动。拖到占用格或棋盘外不移动。
- 技能选择：打开某个战技/秘法槽时，展示该角色职业、该技能类型、1 到当前转数的所有技能图标；不再要求用户先切换转数分页。
- 保留规则：四人上限、重复职业、换职业清技能、宠物复用、同一角色技能去重、降转清超阶技能保持不变。

## 交互设计

- 站位盘仍是 5×4。
- 有角色的格子可拖动；拖动时原格和当前悬停空格会出现视觉反馈。
- 点击空格仍用于新增角色；点击角色仍用于选中/取消；选中角色后点击空格仍可移动，作为键盘与非拖拽替代路径。
- 技能选择器顶部显示“当前职业 / 当前转数范围 / 战技或秘法”，下面按转数分组展示全部图标。

## 测试设计

- 端到端测试覆盖：四转骑士技能选择器能看到 1-4 转技能且看不到 5-7 转；七转术士能看到 1-7 转术士技能。
- 端到端测试覆盖：拖动角色到空位后站位改变，拖到占用格不改变。
- 构建与现有数据校验保持通过。
