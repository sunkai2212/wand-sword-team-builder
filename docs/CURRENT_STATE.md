# 当前状态与交接

## 产品现状

这是一个无需登录和后端的静态网页工具，用于编辑《杖剑传说》4v4 阵容并在浏览器本地导出 PNG。

- 全队共用 1–7 转；降转时会提示，并只清除高于新转数的技能。
- 5×4 站位盘最多放 4 名成员，支持拖拽、键盘操作与触控移动。
- 可选骑士、斗士、术士、贤者；成员可填写中文队员 ID。未填写时使用“队员 1”等兜底名称。
- 每名成员有 4 个战技槽、4 个秘法槽和 1 个宠物槽。技能选择器显示从 1 转到当前转数的全部同职业、同类型图标；不显示技能名称、效果或数值。
- 技能可留空，至少添加 1 名成员即可导出。宠物可被不同成员重复选择。
- 图标目录包含 380 个技能、5 个宠物与 4 个职业形象。

## 素材真相

- `data/source-assets.json` 是裁切、尺寸、圆形蒙版和输出路径的权威来源。
- 1–6 转使用已提交的 `data/source/manual/detail/` 稳定源图；7 转使用 `data/source/seventh/`。执行 `npm run assets:build` 可在另一台机器重新生成输出。
- `技能图标/` 是本机原始详情截图，未提交，不是构建或 CI 前提。离线整理脚本在该目录存在时才执行原图检查。
- 六转骑士战技槽 1 使用耀光灵刃，槽 4 使用蓝色水系图标；两者已有回归测试，改图前先核对槽位。

## 开发与发布

```powershell
npm test -- --run
npm run data:check
npm run assets:build
npm run build:pages
```

推送 `master` 后，GitHub Actions 会运行数据校验、单元测试和 `npm run build:pages`，然后发布到 GitHub Pages：

<https://sunkai2212.github.io/wand-sword-team-builder/>

最近一次发布应同时确认 Actions 成功与实际页面/资源 URL 可访问。技能资源 URL 带缓存版本参数；修改技能输出时要同步更新 `src/asset-url.ts` 及其测试，避免浏览器继续显示同名旧图。
