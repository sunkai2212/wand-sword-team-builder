# 1–6 转技能图标重建裁切

## 目标

将 1–6 转的所有技能图标重建为与七转示范一致的成品：技能自身的圆形外沿完整贴合 128 × 128 画布，不保留圆外黑色背景、透明缝隙或明显偏位。

## 范围

- 处理 `技能图标` 中的 1–6 转详情截图。
- 覆盖骑士、斗士、术士、贤者；共享的一转技能复用同一份源图。
- 七转图标不修改，继续作为视觉基准。
- 不增加技能说明、名称或界面功能。

## 方法

1. 从每张技能详情截图中提取右侧技能圆框，而不是继续从旧的合集截图使用通用坐标。
2. 将提取结果裁成正方形并缩放至 128 × 128；圆形蒙版半径为画布的一半，使圆边与画布边缘相接。
3. 先通过现有图标和职业/转数目录交叉匹配输入与输出，无法可靠匹配的条目不替换。
4. 七转的 48 个条目保持源文件、裁切参数与输出不变。

## 验收

- 1–6 转成品的圆形边缘到达画布边缘；圆外不出现旧截图的黑色底。
- 1–6 转技能与原职业、转数、战技/秘法条目保持对应。
- 七转文件的清单条目与生成结果不变。
- 数据校验、测试、网页构建通过；图标地址更新缓存版本以避免浏览器显示旧文件。

## 风险与处理

详情截图的随机文件名不承载技能名称，因此对应关系必须先自动交叉验证。若某一张无法达到确定阈值，保留旧成品并记录为待人工确认，不能把错误图标静默写入其他技能。
